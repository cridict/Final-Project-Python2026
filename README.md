# Vaultapp
This is our program that me and my partner made that saves passwords, It is called VaultApp. We made it so you can type in a website and the password you use for it.
# How it works
You type in a website name and a password and click Save Password. It saves it to a file on your computer. If you want to find a password you saved you just type the website name and click Search for Password. You can also click Check Strength to see if your password is weak or strong. The API Security Check button goes online and checks if your password was ever stolen in a hack.
