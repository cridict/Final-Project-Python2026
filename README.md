# VaultApp
VaultApp is a app that me and my partner made for the Python final. It is used to save passwords for different websites and help keep them organized and secure.

# Features
* Save passwords for websites
* Search for saved passwords
* Check if a password is weak or strong
* API security check to see if a password was leaked in a data breach
* Clear all saved passwords
* Delete one saved password entry
* Count how many passwords are saved
* Update a password for a website

# How It Works
1. Type in a website name and password.
2. Click **Save Password** to save it to a file on your computer. Meaning it is completely in your hands and no one else, not even us, can access it.
3. To find a saved password, type the website name and click **Search for Password**.
4. Click **Check Strength** to test if the password is strong or weak.
5. Click **API Security Check** to check online if the password has been found in a hack or data breach.
6. You can also delete one saved password, update an old password, or see how many passwords are stored.

# Installation
First install the requests library. This is the only way this app can lauch:

pip install requests

# Running the Program
Run the program with:

python VaultApp.py
